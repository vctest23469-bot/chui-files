# Chui Files 0.1.9 · 首次公开发布

Chui Files 现以 MIT 许可证开源。它是一款 SwiftUI + AppKit 实现的 macOS 原生双栏文件管理器，面向本地文件查找、预览、整理和目录同步。

## 下载与安装

下载本页附件 `Chui-Files-0.1.9-universal.dmg`，打开后将应用拖入 Applications。一个安装包包含 Intel x86_64 与 Apple Silicon arm64，最低支持 macOS 14。

`SHA256SUMS.txt` 提供安装包校验值。将两个附件放在同一目录，执行 `shasum -a 256 -c SHA256SUMS.txt`。GitHub 自动提供对应标签的源码 ZIP / TAR.GZ。

## 本次版本

- 双栏、多标签、收藏、路径导航与栏内自动搜索，结合 Quick Look 和轻量文本编辑。
- 文件夹逻辑大小后台计算，包含隐藏文件，不跟随符号链接；支持文件与文件夹混合排序和可选的文件夹优先。
- 复制和跨卷移动显示实际字节进度、平均速度与预计剩余时间。同卷移动使用直接重命名。
- 目录差异预览、选择同步、排除规则与目录对预设；保留同名跳过或保留两份等处理方式。
- 原创应用、DMG 文件及挂载卷图标，应用包附带 MIT 许可证。
- 补齐中文 README、更新记录、贡献指南与可复用的项目介绍。

## 已知限制

- 使用 ad-hoc 签名，尚无 Developer ID 签名或 Apple 公证；首次打开可能被系统拦截。请核对来源与校验值，通过系统“隐私与安全性”处理提示，无需全局关闭 Gatekeeper。
- Intel 真机运行仍待验证；此次发布未执行完整界面回归，编译成功不等于所有硬件环境均已验收。
- 取消只停止后续项目，当前项目继续完成；不提供单文件暂停续传或完整事务回滚。
- 目录同步基于大小与修改时间，不是基于内容哈希的镜像备份；文件夹逻辑大小不等于 APFS 实际独占空间。
- DMG 文件外观的自定义图标依赖 macOS 扩展属性，下载后可能显示默认磁盘映像图标；包内应用和挂载卷图标保留。

项目仍处于 0.1.x 阶段，欢迎通过 Issues 提交复现步骤、系统版本和脱敏样本。
