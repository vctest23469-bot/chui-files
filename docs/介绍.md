# Chui Files 项目介绍

## 一句话介绍

Chui Files 是一款开源的 macOS 原生双栏文件管理器，把本地文件的查找、预览、搬运和目录差异同步放在同一个窗口中。

## 完整介绍

当工作涉及多个目录、外接磁盘或两份资料副本时，频繁切换窗口会打断整理过程。Chui Files 用左右双栏呈现源目录与目标目录，结合多标签、收藏、路径导航和栏内自动搜索，让常见操作保持在当前上下文中完成。

它不仅展示文件列表，也提供真实的文件操作反馈：文件夹大小在后台计算，复制和跨卷移动显示已传字节、平均速度与预计剩余时间，目录同步先显示差异再选择执行。预览使用 macOS Quick Look，文本可在轻量编辑器中修改；同名处理、排除规则和操作日志让处理过程更容易核对。

项目使用 SwiftUI 与 AppKit，面向 macOS 14 及以上系统，提供 Intel 与 Apple Silicon 通用安装包。源码以 MIT 许可证公开，欢迎反馈问题和参与贡献。

当前仍处于 0.1.x 阶段：没有远程协议、云盘连接、单文件暂停续传或完整事务回滚；安装包尚未做 Apple 公证，Intel 真机运行仍待验证。适合希望用轻量原生工具整理本地文件、也愿意参与开源改进的用户。

## 可直接使用的发布短文
